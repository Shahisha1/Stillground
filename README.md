# Stillground

A small Fabric mod for Minecraft Java Edition that adds rare, quiet abandoned campsites to suitable wilderness biomes.

Stillground keeps the vanilla survival loop intact: campsites are sparse, campfires are cold, sleeping bags are portable decorations rather than beds, and loot is modest.

## Project status

Initial repository setup. Source implementation and verified build are not yet present.

## Planned baseline

- Minecraft Java Edition 1.21.1
- Fabric Loader
- Java 21
- Gradle build
- Mod ID: `stillground`
- Package: `com.shahisha.stillground`

## Design

Muted earth tones, compact footprints, minimal debris, and rare generation. No CurseForge project is planned; GitHub is the project's home.
