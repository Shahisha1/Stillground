# Stillground

A small Fabric mod for Minecraft Java Edition 26.3 that adds rare, quiet abandoned campsites to suitable wilderness biomes.

Stillground keeps the vanilla survival loop intact: campsites are sparse, campfires are cold, sleeping bags are portable decorations rather than beds, and loot is modest.

## Project status

The repository has been initialized and its build configuration now targets Minecraft 26.3 and Java 25. The gameplay implementation is still in progress and has not yet been verified with a successful build or an in-game test.

- Mod ID: `stillground`

## Design

Muted earth tones, compact footprints, minimal debris, and rare generation. No CurseForge project is planned; GitHub is the project's home.
